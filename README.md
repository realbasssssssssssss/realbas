# เกมออฟฟิศ — เกมออนไลน์สำหรับเล่นกับเพื่อนร่วมงาน (UNO, COUP)

เกม UNO Flip แนวพิกเซลอาร์ต เล่นผ่านเบราว์เซอร์ ไม่ต้องติดตั้งอะไรฝั่งผู้เล่น
มี **การ์ดด้านสว่าง ☀ และด้านมืด 🌙 (กลับด้านได้)**, เล่นออนไลน์กับเพื่อนร่วมงาน 2–10 คน, **แชทพิมพ์คุยอยู่ด้านล่าง ทุกคนเห็น**, และมีบอทไว้เติมโต๊ะ

## เปิดเกม (1 คนในออฟฟิศเป็นเจ้าของเซิร์ฟเวอร์)

ต้องมี [Node.js](https://nodejs.org) 16 ขึ้นไป

- **Windows:** ดับเบิลคลิก `start.bat`
- **Mac/Linux:** `./start.sh` หรือ `npm start`

หน้าต่างจะแสดงที่อยู่ เช่น
```
เครื่องนี้:       http://localhost:3000
เพื่อนในออฟฟิศ:  http://192.168.1.25:3000   <-- ส่งลิงก์นี้ให้เพื่อน
```
เพื่อนที่ต่อ Wi-Fi/LAN เดียวกันเปิดลิงก์นั้นได้เลย (ถ้าเปิดไม่ติด ให้อนุญาตพอร์ต 3000 ใน Windows Firewall)

> ใช้นอกวง LAN (เช่น ทำงานจากบ้าน) → นำโฟลเดอร์นี้ไป deploy บริการที่รัน Node.js ได้ (Render, Railway, Fly.io ฯลฯ)
> ใช้คำสั่ง start `node server.js` — เกมรองรับ `wss://` อัตโนมัติเมื่อเปิดผ่าน HTTPS

ตัวเลือก (ตัวแปรสภาพแวดล้อม): `PORT` (ค่าเริ่มต้น 3000), `TURN_MS` เวลาต่อตา (45000), `BOT_DELAY` ความเร็วบอท (1200)

## วิธีเล่น
1. ใส่ชื่อ → **สร้างห้องใหม่** → ส่งรหัสห้อง 4 ตัว หรือกด "คัดลอกลิงก์ชวนเพื่อน"
2. หัวห้องเพิ่ม 🤖 บอทได้ แล้วกด **เริ่มเกม** (ขั้นต่ำ 2 คน)
3. ถึงตาคุณ: กดการ์ดที่ **ส่องแสงเหลือง** หรือกด **จั่ว** (คีย์ลัด `D` จั่ว, `P` ผ่านตา, `U` UNO, `C` จับ UNO)
4. เหลือ 1 ใบ ต้องกด **UNO!** ก่อนคนถัดไปลง ไม่งั้นโดน **จับ** จั่ว 2 ใบ
5. ใครหมดมือก่อนชนะรอบ — เล่นต่อได้เรื่อย ๆ มีสถิติ 🏆 สะสม

## ตั้งค่าห้อง (หัวห้องเลือกได้ก่อนเริ่มเกม และก่อนเล่นรอบใหม่)
- **โหมดเกม:** 🎴 *ธรรมดา* (UNO คลาสสิก 108 ใบ: 0–9, Skip, Reverse, +2, Wild, Wild +4) หรือ 🌓 *FLIP* (112 ใบ สว่าง/มืด)
- **ลืมพูด UNO แล้วถูกจับ:** จั่ว 1 ใบ หรือ 2 ใบ
- แอบดูด้านหลังการ์ดคนอื่น (ใช้ได้เฉพาะโหมด Flip)

## กติกา Flip
| | ☀ ด้านสว่าง | 🌙 ด้านมืด |
|---|---|---|
| สี | แดง เหลือง เขียว น้ำเงิน | ชมพู เขียวน้ำทะเล ส้ม ม่วง |
| จั่ว | **+1** | **+5** |
| ข้าม | Skip (ข้าม 1 คน) | **Skip Everyone** (ข้ามทุกคน เล่นต่อ) |
| Wild | Wild +2 | **Wild Draw Color** (จั่วจนได้สีที่เลือก) |
| ทั้งสองด้าน | Reverse, **Flip** (พลิกการ์ดทั้งโต๊ะ: มือ/กองจั่ว/กองทิ้ง), Wild | |

- **ท้า (Challenge):** ถูกลง Wild +2 / Wild +4 / Wild Draw Color ใส่ เลือก *ท้า* ได้ — ถ้าคนลงมี **สีเดิมของใบก่อนหน้า** ในมือ เขาจั่ว 4 ใบ ถ้าไม่ได้โกง ผู้ท้าจั่วเพิ่ม 2 ใบ
- 2 คน: Reverse ทำหน้าที่เหมือน Skip (ได้เล่นต่อ)
- ลงหลังจั่ว: จั่วมาแล้วเล่นได้เฉพาะใบที่เพิ่งจั่ว หรือกด "ผ่านตา"
- ถ้า Flip เปิดเจอ Wild ใครจะลงอะไรก็ได้
- ตัวเลือกห้อง **"แอบดูด้านหลังการ์ดคนอื่น"** — เห็นสีด้านหลังการ์ดของคู่แข่งเหมือนเล่นการ์ดจริง
- ครบเวลาต่อตา (45 วิ) ระบบจั่ว/ผ่านให้ ถ้าหลุดเน็ตหรือหายไป 2 ครั้งติด บอทจะเล่นแทนชั่วคราว กลับมากดอะไรก็ได้เพื่อรับช่วงคืน
- หลุดการเชื่อมต่อ เปิดหน้าเดิมอีกครั้งจะกลับเข้าที่นั่งเดิมอัตโนมัติ

## โครงสร้างไฟล์
```
server.js          เซิร์ฟเวอร์ (HTTP + WebSocket, กติกา, ห้อง, บอท, แชท)
public/index.html  หน้าเกม      public/style.css  สไตล์พิกเซล
public/app.js      ฝั่งผู้เล่น   public/cards.js    วาดการ์ด/ไอคอนพิกเซล
public/sound.js    เสียง 8-bit (สร้างด้วย WebAudio ไม่มีไฟล์เสียง)
public/fonts/      ฟอนต์ Press Start 2P (SIL OFL)
```
สถานะเกมเก็บในหน่วยความจำ — รีสตาร์ทเซิร์ฟเวอร์ ห้องจะหายไป

## เคล็ดลับ
- อยากลองเล่นคนเดียวหลายแท็บในเครื่องเดียว: เปิด `http://localhost:3000/?p=2` (เลขต่างกัน = คนละตัวตน) หรือกดเพิ่มบอทแทน
- ระบบจำผู้เล่นด้วยเบราว์เซอร์ (ปิดแท็บแล้วเปิดใหม่จะกลับที่นั่งเดิม) ถ้าอยากเปลี่ยนชื่อ ให้ออกจากห้องก่อน

## เล่นผ่านลิงก์ (ไม่ต้องให้คนอื่นลงอะไร)

### วิธีที่ 1 — เร็วสุด ไม่ต้องสมัครอะไร: ดับเบิลคลิก `start-online.bat`
เครื่องคนเปิดต้องมี Node.js แล้วรอจนขึ้นลิงก์ `https://xxxx.trycloudflare.com` ส่งลิงก์นั้นให้ทุกคน (เปิดบนมือถือได้)
ลิงก์เปลี่ยนทุกครั้งที่เปิดใหม่ และต้องเปิดหน้าต่างทิ้งไว้ตลอดตอนเล่น

### วิธีที่ 2 — ลิงก์ถาวร เปิดเครื่องไว้ไม่ต้อง (ฟรี): Render.com
1. สมัคร github.com และ render.com (ฟรี) แล้วอัปโหลดโฟลเดอร์นี้เป็น repo บน GitHub (ไม่ต้องอัป node_modules)
2. Render > New > Blueprint > เลือก repo นี้ > Apply
3. รอประมาณ 2-3 นาที จะได้ลิงก์ `https://uno-office.onrender.com` ส่งให้ทุกคนได้ตลอด
(ฟรีแพ็กเกจ ถ้าไม่มีคนเข้านาน ๆ ห้องจะหลับ เข้าครั้งแรกรอ ~30 วินาที และห้องที่เปิดไว้จะหายเมื่อเซิร์ฟเวอร์หลับ)


## HAXBALL
เกมฟุตบอลตัวกลม เลือกทีม 1v1–5v5 ลูกเล็ก/ใหญ่ ตั้งเวลาแข่งได้ (ห้องรอ) — W A S D เดิน, Space เตะ/ส่ง, มือถือใช้จอยสติ๊ก + ปุ่มเตะ ทีมที่ไม่ครบบอทเติมให้อัตโนมัติ

## WEREWOLF (เกมหมาป่า)
4–12 คน เลือกจำนวนหมาป่าและบทบาทพิเศษ (หมอดู, หมอ, พราน, แม่มด) ได้ในห้องรอ ที่เหลือเป็นชาวบ้าน คนไม่ครบมีบอทเติมให้ — กลางคืนมีแต่หมาป่าที่คุยกันได้ ผู้ตายคุยกันเองได้
